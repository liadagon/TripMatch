# TripMatch

TripMatch is a React + Vite frontend project. The frontend lives in the `client` folder.

## Project Structure

```text
tripmatch/
  client/
    public/
    src/
      assets/
      Components/
      custom_hooks/
      data/
      services/
      firebase.ts
      App.tsx
      App.css
      index.css
      main.tsx
      vite-env.d.ts
    index.html
    package.json
    package-lock.json
    tsconfig.json
    vite.config.js
    eslint.config.js
    .env
    .env.example
  server/
  README.md
  .gitignore
```

## Frontend Setup

```bash
cd client
npm install
```

## Run Frontend

```bash
npm run dev
```

## Build Frontend

```bash
npm run build
```

## Lint

```bash
npm run lint
```

Backend code has not been implemented yet.
